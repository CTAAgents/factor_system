# 机构版期货核心因子注册表 V1.0 — 使用说明

## 文件结构（5个工作表）
| 工作表 | 作用 |
|---|---|
| **因子注册表** | 核心清单，12个因子的完整字段映射 |
| **标准化方式字典** | `standardization_method` 字段的6种取值与公式 |
| **方向字典** | `direction` 字段的3种取值（正向/反向/双向） |
| **参数JSON模板** | 每个因子 `parameters` 字段的参数名、类型、默认值 |
| **机构复合权重模板** | 3套实盘权重方案（经典CTA / 基本面增强 / 高频截面） |

## 落地步骤
1. **建库**：按"因子注册表"的字段，在数据库中建 `factor_registry`（元数据）+ `factor_value_detail`（日频因子值）两张表。
2. **取数**：行情用复权主力连续合约；库存用交易所仓单+社会库存 asof join 到日频。
3. **计算**：按 `raw_value` 伪代码逐因子实现，先算 `raw_value`，再做 `standardization_method` 指定的标准化，得到 `standardized_value ∈ signal_range`。
4. **合成**：参考"机构复合权重模板"选一套方案，对截面内各因子 zscore 后线性加权，得 `composite_signal`。
5. **回测**：用 `composite_signal` 做分组（五分位）回测，记录 Mean IC / IC IR / 多空夏普 / 最大回撤。
6. **迭代**：任何因子逻辑修改必须升版本号（v1.0→v1.1），旧版本结果冻结不可覆盖。

## 关键约定
- **方向字段**：`正向`=因子值越大越看多；`反向`=因子值越大越看空（代码层需乘 -1 再合成）。
- **截面 vs 时序**：动量类（XSMOM）、偏度、非流动性必须做**截面**标准化；展期收益、库存可做**时序滚动**标准化。
- **数据对齐**：周度基本面因子（库存）用 asof join 映射到日频，禁止简单 forward fill 超过 5 个交易日。
- **成本假设**：回测默认单边成本 = 1跳滑点 + 手续费，建议在 `parameters` 中显式声明。
