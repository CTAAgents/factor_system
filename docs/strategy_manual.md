## 1. 策略概述

### 1.1 策略定位

FTS 沪深 300 因子组合策略是一个**纯多头、日频调仓**的量化选股策略，基于多因子合成框架对沪深 300 成分股进行截面排序，每日持有排名靠前的标的。

### 1.2 核心特征

| 属性 | 值 |
|:-----|:----|
| 标的池 | 沪深 300 成分股 |
| 持仓方向 | 纯多头（不做空） |
| 持仓数量 | 每期 30 只 |
| 调仓频率 | 日频 |
| 因子合成 | 等权合成 |
| 因子数量 | 118 个 |
| 信号来源 | 多因子截面排序 |
| 基准 | 等权持有所有有效标的 |

### 1.3 策略流水线

```text
数据获取 → 因子计算 → 信号合成 → 截面排序 → 选股 → 持仓
   ↑          ↑           ↑           ↑         ↑      ↑
 MCP/akshare  elite因子   等权加权    IC排序    top 30  日频调仓
```

### 6.2 关键发现

- **波动率因子**是表现最好的类别（Sharpe 9.06，收益+251%），仅 4 个因子贡献了组合的核心 alpha
- **宏观代理因子**（PMI 代理）表现同样突出（Sharpe 6.61，收益+230%），9 个因子贡献显著

- 边际贡献分析显示，所有因子类别对组合都有正向贡献，无冗余类别

## 8. 风险控制

### 8.1 风险指标

| 指标 | 值 | 评价 |
|:-----|:----|:-----|
| 最大回撤 | 9.45% | ✅ 优秀（< 15%） |
| 年化波动率 | 35.03% | ⚠️ 较高（A 股特征） |
| 卡玛比率 | 43.03 | ✅ 优秀（> 3） |
| 盈亏比 | 2.03 | ✅ 良好（> 1.5） |
| 月胜率 | 83.33% | ✅ 优秀（> 70%） |

### 8.2 风险来源

1. **市场风险**：熊市期间 Sharpe 降至 1.30，日均收益仅 +15bp，绝对收益有限
2. **行业集中风险**：科技成长类行业（通信、半导体、电子）选择率偏高，防御性行业选入时表现不佳
3. **因子衰减风险**：世坤因子整体 Sharpe 仅 0.89，存在退化风险，需持续监控
4. **换手率风险**：月换手率 19.6%，日频调仓的交易成本需在实际交易中考虑

### 8.3 风险缓释措施

- 正交化处理：剔除因子间高度相关的冗余信息
- 衰减检测：6 个月衰减系数 0.05，过时因子自动降低权重
- 纯多头限制：避免做空带来的无限风险
- 等权合成：避免单一因子主导组合

## 9. 使用说明

### 9.1 运行组合构建

```powershell
# 手动运行 L3 组合构建
fts portfolio run

# 查看当前组合
fts portfolio show
```

### 9.2 查看组合详情

```powershell
# 查看组合配置文件
Get-Content memory/portfolio/current_combo.json | ConvertFrom-Json

# 查看因子权重

```

### 9.3 回测组合

```powershell
python scripts/portfolio_backtest.py
```

### 9.4 分析组合

```powershell
python scripts/portfolio_analysis.py
```

### 9.5 定时调度

组合每周一 06:00 自动运行（L3 Portfolio Loop），可通过调度器查看：

```powershell
fts scheduler list
```
