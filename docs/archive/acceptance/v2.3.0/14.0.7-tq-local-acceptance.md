## 3. 实现要点

### 3.1 类结构

```python
class TQLocalSource(BaseFuturesSource):
    source_name: str = "TQ_LOCAL"
    base_url: str = "http://127.0.0.1:7721"
    rpc_url: str = "http://127.0.0.1:7721/rpc"
    timeout: float = 5.0
```

### 3.2 期货代码 → 交易所推断（5 级匹配）

| 优先级 | 交易所 | 匹配规则 | 示例 |
|:------:|--------|----------|------|
| 1 | CFFEX | 2 字母 (IF/IH/IC/TF/TS/TL) | IF0 → CFFEX |
| 2 | CZCE | 2 字母 (TA/MA/SR/FG/OI/...) | TA0 → CZCE |
| 3 | SHFE | 2 字母 (RB/CU/AU/AG/...) | RB0 → SHFE |
| 4 | DCE | 1 字母 (A/B/C/M/Y/I/J/...) | M0 → DCE |
| 5 | CFFEX | 1 字母兜底 (T = 10 年期国债) | T2509 → CFFEX |

> **关键陷阱**：T 是 CFFEX 10 年期国债期货（1 字母），但 TA 是 CZCE 1-甲胺（2 字母）。所以 `T` 单独匹配必须放在 2 字母匹配之后，避免误覆盖 `TA`。

### 3.3 降级策略

| 场景 | 行为 | 上层处理 |
|------|------|---------|
| 连接失败 / 超时 | `fetch_ohlcv` 抛 `SourceUnavailable` | 聚合器熔断判定 |
| JSON 解析失败 | `fetch_ohlcv_or_none` 返回 `None` | 优雅降级到下一数据源 |
| 缺必填字段 | 抛 `ValueError`（不静默） | 立即告警 |
| HTTP 4xx/5xx | 抛 `SourceUnavailable` | 聚合器熔断判定 |
| `is_available()` 失败 | 返回 `False`（不抛异常） | 探活轮询 |
| `amount` 缺失 | vwap 回退 `(h+l+c)/3` 典型价 | 数据质量标记 |

### 3.4 vwap 计算公式

```python
vwap = amount / volume                    # 主路径（真实成交额）
vwap = (high + low + close) / 3           # 回退路径（典型价）
```
