## 3. 实现要点

### 3.1 `fts data` 子命令组

```
$ fts data --help
usage: fts data [-h] {status,sync-futures,cross-check,fuse} ...

期货多源数据命令（Phase 14.4）

positional arguments:
  {status,sync-futures,cross-check,fuse}
    status              查看多源熔断器/成功率状态
    sync-futures        主动同步期货 K 线数据
    cross-check         对指定 symbol+date 做多源交叉验证
    fuse                多源 K 线融合（14.3 + 14.4）
```

| 子命令 | 参数 | 输出 |
|:-------|:-----|:-----|
| `fts data status` | `--json` | 各源 success/failure/consecutive_failures/circuit_open |
| `fts data sync-futures` | `--symbol` `--days` `--json` | 同步最近 N 天 K 线（最近 5 行 JSON） |
| `fts data cross-check` | `--symbol` `--date` `--json` | 多源分歧告警（无则退出 0） |
| `fts data fuse` | `--symbol` `--strategy` `--days` `--json` `--output` | FusionReport 契约（6 必填 + 4 可选字段） |

**trace_id 全链路**：每个子命令首行打印 `trace_id=...`，贯穿整个执行流（含 `_record_success` / `_record_failure` / `OHLCVFusion.fuse_dataframe` / `cross_check`）。

### 3.2 `FusionReport` 契约

```python
# fts/core/contracts.py
class FusionReport(TypedDict):
    """多源融合报告（v2.3.0+ 14.4 新增）。"""
    # 必填
    trace_id: str                       # 链路追踪 ID
    symbol: str                         # 品种代码
    strategy: str                       # FusionStrategy.name
    rows: list[FusedOHLCV]              # 融合后的 FusedOHLCV 列表
    sources_used: list[str]             # 实际有数据贡献的源名列表
    rows_count: int                     # 融合后行数
    # 可选
    started_at: NotRequired[str]        # ISO 8601
    finished_at: NotRequired[str]       # ISO 8601
    disagreements: NotRequired[list[MultiSourceDisagreement]]
    avg_disagreement_pct: NotRequired[float]
```

**契约优先**：CLI `fts data fuse` 的 JSON 输出、`scripts/verify_multi_source.py` 场景 5 报告落盘、未来调度器日终融合报告均使用本契约。

### 3.3 `_build_default_aggregator` 工厂

```python
def _build_default_aggregator() -> FuturesDataAggregator:
    """构造默认聚合器（按需导入 + 探活）。"""
    sources: list[BaseFuturesSource] = []
    enhancers: list[BaseFuturesSource] = []
    # TQ_LOCAL（主源）
    try:
        from fts.data_sources.tq_source import TQLocalSource
        src = TQLocalSource()
        if src.is_available():
            sources.append(src)
    except Exception:
        pass
    # WIND / IFIND（增强源）
    for cls_name in ("WindSource", "IFindSource"):
        ...
    db_path = Path("data") / "fts_history.duckdb"
    return FuturesDataAggregator(
        sources=sources, enhancers=enhancers,
        db_path=db_path if db_path.exists() else None,
    )
```

**降级友好**：TQ/WIND/IFIND 任意源不可用时不抛错，仅跳过；空聚合器仍可执行（`_cmd_data_fuse` 退化为返回 1）。
