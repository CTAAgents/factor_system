# 从450个原始因子到24个种子因子：期货CTA种子提炼方法论

## 摘要

本文详细阐述了如何从世坤101、Qlib158、国泰君安191共450个股票量价因子中，系统性地提炼出24个适用于期货市场的种子因子。这一过程不是简单的筛选，而是基于**算子骨架去重**、**字段适配性分析**、**市场结构差异**三个维度的深度重构。最终形成的24个种子因子作为遗传算法的初始种群，为演化引擎提供了高质量的搜索起点。

---

## 1. 背景与挑战

### 1.1 原始因子库概况

FTS系统集成了三套业界知名的量价因子库：

| 因子库 | 数量 | 来源 | 特点 |
|--------|------|------|------|
| 世坤101 (WorldQuant Alpha#101) | 101个 | WorldQuant LLC论文 | 经典量价算子组合，覆盖动量、反转、波动率等基础模式 |
| Qlib158 | 158个 | 微软Qlib框架 | 系统化因子工程，包含K线形态、技术指标、统计特征 |
| 国泰君安191 | 191个 | 国泰君安研报 | 中国市场实证验证，高频因子日频化改造 |
| **合计** | **450个** | - | 大量重复骨架，参数变体众多 |

### 1.2 核心挑战

直接将450个股票因子迁移到期货市场面临三重障碍：

1. **字段不兼容**：股票因子依赖`industry`（行业分类）、`cap`（市值）、精确`vwap`（成交量加权平均价），期货主连合约日频数据无法提供这些字段
2. **截面维度缺失**：期货市场仅有25-82个品种（vs 股票5000+），截面统计意义弱，`cs_rank`、`cs_zscore`等截面算子失效
3. **参数冗余**：450个因子中存在大量"同骨架、不同参数"的变体（如ROC5/ROC10/ROC20/ROC60），直接注入会导致初始种群高度相关

---

## 2. 提炼方法论：四层筛选框架

我们设计了**四层筛选框架**，从450个原始因子中逐步提炼出24个高质量种子：

```
┌─────────────────────────────────────────┐
│ Layer 1: 算子骨架去重                    │  450 → ~200个独立骨架
│ 识别因子的核心算子组合，合并参数变体      │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│ Layer 2: 字段适配性过滤                  │  ~200 → ~80个
│ 剔除依赖industry/cap/vwap的因子          │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│ Layer 3: 截面算子剔除                    │  ~80 → ~40个
│ 移除依赖cs_rank/cs_zscore的因子          │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│ Layer 4: 质量与置信度筛选                │  ~40 → 24个
│ 保留高置信度、期货逻辑清晰的因子          │
└─────────────────────────────────────────┘
```

### 2.1 Layer 1: 算子骨架去重

**核心思想**：种子因子只需覆盖**不同的算子骨架**，参数变异交给演化引擎探索。

#### 示例：动量因子骨架

原始因子库中存在大量动量变体：

| 原始因子 | 公式 | 骨架 |
|----------|------|------|
| Qlib-ROC5 | `(close - delay(close, 5)) / delay(close, 5)` | ROC(close, N) |
| Qlib-ROC10 | `(close - delay(close, 10)) / delay(close, 10)` | ROC(close, N) |
| Qlib-ROC20 | `(close - delay(close, 20)) / delay(close, 20)` | ROC(close, N) |
| Qlib-ROC60 | `(close - delay(close, 60)) / delay(close, 60)` | ROC(close, N) |
| WQ#24 | `rank(delay(close, 5) - close) / delay(close, 5)` | ROC(close, N)变体 |

**去重策略**：保留2个代表（5日短期、20日中期），参数优化由演化引擎通过变异算子自动探索。

#### 示例：波动率因子骨架

| 原始因子 | 公式 | 骨架 |
|----------|------|------|
| Qlib-STD5 | `std(returns, 5)` | STD(returns, N) |
| Qlib-STD10 | `std(returns, 10)` | STD(returns, N) |
| Qlib-STD20 | `std(returns, 20)` | STD(returns, N) |
| Qlib-STD60 | `std(returns, 60)` | STD(returns, N) |
| WQ#34 | `std(returns, 20) / mean(std(returns, 5), 20)` | STD比率 |

**去重策略**：保留2个标准差（5日短期、20日中期）+ 1个波动率比（短期/长期）。

#### 去重统计

| 骨架类别 | 原始因子数 | 去重后保留 | 淘汰数量 |
|----------|------------|------------|----------|
| 动量/反转 (ROC) | ~60个 | 3个 | ~57个 |
| 波动率 (STD) | ~45个 | 3个 | ~42个 |
| K线形态 (KBAR) | ~30个 | 4个 | ~26个 |
| 量价相关性 (CORR) | ~25个 | 1个 | ~24个 |
| 趋势特征 (SLOPE/RSQR) | ~20个 | 2个 | ~18个 |
| 其他 | ~270个 | ~11个 | ~259个 |
| **合计** | **450个** | **24个** | **~426个** |

### 2.2 Layer 2: 字段适配性过滤

**核心问题**：股票因子依赖的字段在期货主连日频架构下不可用或不可靠。

#### 字段可用性分析

| 字段 | 股票 | 期货主连日频 | 影响 |
|------|------|--------------|------|
| `open/high/low/close` | ✅ 精确 | ✅ 精确 | 无影响 |
| `volume` | ✅ 精确 | ✅ 精确 | 无影响 |
| `vwap` | ✅ 精确 | ⚠️ 不可靠 | 主连合约日频vwap是合成值，信号不可靠 |
| `industry` | ✅ 有 | ❌ 无 | 行业中性化、板块轮动因子失效 |
| `cap` (市值) | ✅ 有 | ❌ 无 | 市值加权、规模因子失效 |
| `settle` (结算价) | ❌ 无 | ✅ 有 | 期货特有，可替代部分vwap功能 |
| `hold` (持仓量) | ❌ 无 | ✅ 有 | 期货最核心字段，资金流信号 |

#### VWAP依赖因子处理

国泰君安191中约30个因子依赖精确vwap：

```python
# 示例：GTJA#5 VWAP偏离因子
def factor_program(data, params):
    vwap = data['vwap']  # ❌ 期货主连日频不可靠
    close = data['close']
    return (close - vwap) / vwap
```

**处理策略**：
- **方案A**：用`(high + low + close) / 3`（典型价格）近似替代 → 标记为"低置信度"
- **方案B**：用`settle`（结算价）替代 → 标记为"低置信度"
- **方案C**：直接剔除 → 保留2个VWAP改造版作为探索

最终保留2个VWAP改造版（`seed_vwap_proxy_1`, `seed_vwap_proxy_2`），标记为低置信度，IC阈值从0.03提高到0.08。

#### 剔除统计

| 剔除原因 | 影响因子数 | 示例 |
|----------|------------|------|
| 依赖`industry` | ~40个 | 行业中性化因子、板块轮动因子 |
| 依赖`cap` | ~20个 | 市值加权因子、规模因子 |
| 依赖精确`vwap` | ~30个 | GTJA#5/#11/#15等 |
| **合计** | **~90个** | - |

### 2.3 Layer 3: 截面算子剔除

**核心问题**：期货市场品种数量太少（25-82个），截面统计意义弱。

#### 截面算子对比

| 算子 | 股票市场 | 期货市场 | 适用性 |
|------|----------|----------|--------|
| `cs_rank` | 5000+品种排名 | 25-82品种排名 | ⚠️ 统计噪声大 |
| `cs_zscore` | 标准化有效 | 标准化不稳定 | ⚠️ 样本量不足 |
| `cs_scale` | 缩放有效 | 缩放不稳定 | ⚠️ 样本量不足 |
| `cs_ind_neutralize` | 行业中性化 | ❌ 无行业分类 | ❌ 完全不可用 |

#### 剔除策略

依赖截面算子的因子被剔除或简化：

```python
# 示例：WQ#3 截面排名因子
def factor_program(data, params):
    close = data['close']
    # ❌ 期货品种太少，cs_rank不稳定
    return cs_rank(close)  

# 改造方案：用时序排名替代
def factor_program(data, params):
    close = data['close']
    # ✅ 单品种内部时序排名
    return ts_rank(close, 20) / 20
```

**剔除统计**：约40个因子因依赖截面算子被剔除。

### 2.4 Layer 4: 质量与置信度筛选

**核心思想**：保留高置信度、期货逻辑清晰的因子。

#### 置信度评估维度

| 维度 | 评估标准 | 权重 |
|------|----------|------|
| **理论支撑** | 是否有学术论文/研报支持 | 25% |
| **行为逻辑** | 是否反映市场参与者行为模式 | 25% |
| **微观结构** | 是否捕捉市场微观结构特征 | 25% |
| **制度因素** | 是否符合期货交易制度 | 25% |

#### 期货特有因子优先

以下期货特有因子被优先保留：

| 因子 | 公式 | 逻辑 |
|------|------|------|
| `seed_oi_chg` | `(oi - delay(oi, 1)) / delay(oi, 1)` | 持仓量变化反映资金流入/流出 |
| `seed_oi_ret_confirm` | `sign(close_delta) * sign(oi_delta)` | 价格上涨+持仓增加=多头入场确认 |
| `seed_spread` | `(ma5 - ma20) / ma5` | 期限结构/展期收益 |
| `seed_settle_bias` | `(close - settle) / settle` | 收盘尾盘博弈 |

## 3. 最终种子因子：24个因子的分类体系

经过四层筛选，最终形成**14大因子家族、24个种子因子**：

### 3.1 因子家族分布

| 家族 | 数量 | 代表因子 | 来源 |
|------|------|----------|------|
| K线形态 | 4个 | `seed_kbar_mid`, `seed_kbar_upper`, `seed_kbar_lower`, `seed_kbar_shift` | Qlib-KBAR, GTJA#2 |
| 多空平衡 | 1个 | `seed_bull_bear` | GTJA#2, Alpha#2 |
| 反转 | 1个 | `seed_reversal_1d` | WQ#4, WQ#38 |
| 动量 | 2个 | `seed_mom_5d`, `seed_mom_20d` | Qlib-ROC, WQ#24 |
| 波动率 | 3个 | `seed_vol_5d`, `seed_vol_20d`, `seed_vol_ratio` | Qlib-STD, WQ#34 |
| 趋势 | 2个 | `seed_trend_slope`, `seed_trend_rsqr` | Qlib-BETA, Qlib-RSQR |
| 极值位置 | 2个 | `seed_argmax_close`, `seed_argmin_close` | WQ#1, Qlib-IMAX |
| 量价相关 | 1个 | `seed_vp_corr` | WQ#3, WQ#6, GTJA#14 |
| 成交量 | 2个 | `seed_vol_chg`, `seed_vol_ratio_volume` | WQ#2, Qlib-VMA |
| 持仓量 | 2个 | `seed_oi_chg`, `seed_oi_ret_confirm` | 期货特有 |
| 期限结构 | 1个 | `seed_spread` | 期货特有 |
| 结算价偏离 | 1个 | `seed_settle_bias` | 期货特有 |
| VWAP改造 | 2个 | `seed_vwap_proxy_1`, `seed_vwap_proxy_2` | WQ#5改造, WQ#11改造 |
| **合计** | **24个** | - | - |

### 3.2 因子详细列表

#### K线形态（4个）

```python
# seed_kbar_mid: K线中点
(close - open) / open

# seed_kbar_upper: 上影线
(high - max(open, close)) / open

# seed_kbar_lower: 下影线
(min(open, close) - low) / open

# seed_kbar_shift: K线偏移（收盘在K线中的位置）
(2*close - high - low) / open
```

**逻辑**：K线形态反映日内多空博弈结果，期货K线更连续（无涨跌停限制），形态信号更可靠。

#### 动量/反转（3个）

```python
# seed_reversal_1d: 1日反转
rank(-delta(close, 1))  # 简化为 -sign(delta)

# seed_mom_5d: 5日动量
(close - delay(close, 5)) / delay(close, 5)

# seed_mom_20d: 20日动量
(close - delay(close, 20)) / delay(close, 20)
```

**逻辑**：短期反转（1-5日）与中期动量（20日）在期货市场并存，反映不同时间尺度的价格趋势。

#### 波动率（3个）

```python
# seed_vol_5d: 5日波动率
std(returns, 5)

# seed_vol_20d: 20日波动率
std(returns, 20)

# seed_vol_ratio: 波动率比（短期/长期）
std(returns, 5) / std(returns, 20)
```

**逻辑**：波动率是风险的核心度量，波动率比反映市场状态切换（趋势vs震荡）。

#### 趋势（2个）

```python
# seed_trend_slope: 趋势斜率
slope(close, 20) / close

# seed_trend_rsqr: 趋势拟合优度
rsquare(close, 20)
```

**逻辑**：线性回归斜率衡量趋势强度，R²衡量趋势稳定性，两者结合识别"强趋势"品种。

#### 极值位置（2个）

```python
# seed_argmax_close: 20日最高价新鲜度
argmax(close, 20) / 20

# seed_argmin_close: 20日最低价新鲜度
argmin(close, 20) / 20
```

**逻辑**：极值位置反映价格突破状态，`argmax/20`接近1表示近期创新高，趋势延续信号。

#### 量价关系（3个）

```python
# seed_vp_corr: 量价相关性
corr(rank(volume), rank(close), 10)

# seed_vol_chg: 成交量变化率
log(volume) - log(delay(volume, 1))

# seed_vol_ratio_volume: 成交量比
volume / mean(volume, 20)
```

**逻辑**：量价配合是趋势确认的核心，放量上涨=多头强势，缩量上涨=趋势衰竭。

#### 期货特有（4个）

```python
# seed_oi_chg: 持仓量变化率
(oi - delay(oi, 1)) / delay(oi, 1)

# seed_oi_ret_confirm: 持仓确认
sign(close - delay(close,1)) * sign(oi - delay(oi,1))

# seed_spread: 期限结构/展期收益
(close_near - close_far) / close_near  # 用ma5/ma20近似

# seed_settle_bias: 结算价偏离
(close - settle) / settle
```

**逻辑**：持仓量是期货独有的信息源，`价格上涨+持仓增加=多头入场`是期货特有的Alpha信号。期限结构（近远月价差）是期货定价的核心。

#### VWAP改造（2个，低置信度）

```python
# seed_vwap_proxy_1: 典型价格替代VWAP
(close - (high+low+close)/3) / ((high+low+close)/3)

# seed_vwap_proxy_2: 结算价替代VWAP
sign(close - settle) * sign(settle / delay(settle, 5))
```

**逻辑**：GTJA191中30+个因子依赖VWAP，主连日频vwap不可靠，用典型价格/结算价近似替代，标记为低置信度（IC阈值0.08 vs 0.03）。

## 4. 设计考量：为什么是24个？

### 4.1 种子定位：初始种群，不是最终因子

**核心理念**：种子因子的职责是**确保初始种群不盲目搜索**，覆盖已验证的因子骨架。

```
种子因子（24个）→ 演化引擎 → 精英因子（数百个）
     ↑                              ↑
  覆盖骨架                     参数优化+组合创新
```

- **种子提供先验知识**：24个骨架覆盖13类量价关系，确保演化起点不偏离合理区域
- **演化提供发现能力**：遗传算法通过变异（改参数、改算子）和交叉（合并因子）自动探索新组合

### 4.2 多样性 vs 冗余的平衡

| 策略 | 优点 | 缺点 |
|------|------|------|
| 保留450个原始因子 | 覆盖全面 | 高度冗余，初始种群相关性高，演化效率低 |
| 保留24个骨架 | 多样性高，冗余低 | 可能遗漏某些特殊模式 |
| **折中方案** | 24个骨架 + 演化探索 | ✅ 兼顾效率与覆盖 |

### 4.3 期货特有因子的权重

24个种子中有4个是期货特有（持仓量、期限结构、结算价偏离），占比17%。这一比例反映了：

- **股票因子库的局限性**：450个原始因子几乎没有期货特有逻辑
- **期货Alpha的独特性**：持仓量、期限结构是期货定价的核心，必须显式编码
- **演化引擎的引导**：种子中的期货特有因子会引导演化引擎重点探索这个方向

### 4.4 VWAP改造因子的争议

保留2个低置信度VWAP改造因子（`seed_vwap_proxy_1`, `seed_vwap_proxy_2`）是有意为之：

- **探索价值**：虽然主连日频vwap不可靠，但典型价格/结算价可能在某些品种上有效
- **熔断保护**：IC阈值从0.03提高到0.08，低质量因子会被快速淘汰
- **信息保留**：GTJA191中30+个因子依赖VWAP，完全剔除会丢失大量信息

## 5. 演化引擎的后续工作

种子因子只是起点，演化引擎会从24个骨架出发，自动探索：

### 5.1 参数变异

```python
# 种子：seed_mom_5d (5日动量)
(close - delay(close, 5)) / delay(close, 5)

# 演化可能产生：
(close - delay(close, 7)) / delay(close, 7)  # 参数变异：5→7
(close - delay(close, 3)) / delay(close, 3)  # 参数变异：5→3
```

### 5.2 算子组合

```python
# 种子：seed_vol_5d + seed_trend_slope
std(returns, 5) + slope(close, 20) / close

# 演化可能产生：
std(returns, 5) * slope(close, 20) / close  # 乘法组合
std(returns, 5) / (slope(close, 20) / close + 1e-10)  # 除法组合
```

### 5.3 期货特有逻辑扩展

```python
# 种子：seed_oi_chg
(oi - delay(oi, 1)) / delay(oi, 1)

# 演化可能产生：
(oi - delay(oi, 1)) / delay(oi, 1) * sign(close - delay(close, 1))  # 持仓变化×价格方向
(oi - delay(oi, 5)) / delay(oi, 5)  # 参数变异：1→5
```

## 6. 总结

从450个原始因子到24个种子因子的提炼过程，本质上是**知识压缩**：

| 维度 | 原始因子库 | 种子因子 | 压缩比 |
|------|------------|----------|--------|
| 数量 | 450个 | 24个 | 18.75:1 |
| 骨架覆盖 | 大量重复 | 13类独立骨架 | 100% |
| 字段依赖 | industry/cap/vwap | open/high/low/close/volume/hold/settle | 期货适配 |
| 市场适配 | 股票市场 | 期货市场 | 完全适配 |

这24个种子因子不是"450个因子的子集"，而是"450个因子的压缩表示"。演化引擎负责"解压缩+创新"，从24个骨架出发，自动探索出数百个适应期货市场的精英因子。

**核心设计原则**：
1. **骨架覆盖 > 参数穷举**：保留代表性骨架，参数变异交给演化
2. **期货适配 > 股票迁移**：显式编码期货特有逻辑（持仓量、期限结构）
3. **多样性 > 完整性**：24个独立骨架优于450个冗余因子
4. **演化引导 > 人工穷举**：种子提供先验，演化提供发现
