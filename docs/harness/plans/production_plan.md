## 2. 实施路线图

### Phase 1: 基础部署（P0 项）

**目标**: 能在生产环境启动并稳定运行

- [ ] 编写 Dockerfile（基于 python:3.12-slim）
- [ ] 编写 docker-compose.yml（FTS + 配置挂载）
- [ ] 配置 CI/CD 流水线（push 后自动构建镜像）
- [ ] 实现熔断告警通知
- [ ] 配置 systemd 服务（Windows 服务或 Linux systemd）

### Phase 2: 可观测性（P1 项）

**目标**: 能监控系统运行状态并快速定位问题

- [ ] 结构化日志（JSON 格式，按天轮转）
- [ ] Prometheus 指标暴露（`/metrics` 端点）
- [ ] Grafana 仪表盘模板
- [ ] 告警通道配置（企业微信/钉钉机器人）
- [ ] 环境变量管理（`python-dotenv`）

### Phase 3: 持续集成（P1 项）

**目标**: 自动化测试和部署流程

- [ ] GitHub Actions 工作流（lint + test + build）
- [ ] 自动回归测试（每日定时运行）
- [ ] 镜像标签管理（`latest` + `v*.*.*`）
- [ ] 数据库/数据备份策略

### Phase 4: 生产加固（P2 项）

**目标**: 提升系统生产级健壮性

- [ ] 容器资源限制（CPU/内存）
- [ ] 健康检查 liveness/readiness probe
- [ ] 配置热重载（已实现基础版，需增强）
- [ ] 多实例部署支持（分布式锁）
- [ ] 安全审计（依赖扫描、密钥管理）
