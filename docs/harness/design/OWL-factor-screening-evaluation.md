## 一、评估背景与结论摘要

### 1.1 背景

内部候选因子数量随 L1/L2 演化持续膨胀（"因子动物园"），因子间高度相关导致：① 组合权重不稳定（LASSO 在强相关变量下任意挑代表）；② Fama-MacBeth 回归对共线性敏感（Kleibergen 2009）；③ 现有信号相关性聚类只能反映"信号层面"冗余，无法直接回答"哪些因子对横截面收益提供了独立解释力"（Cochrane 2011 问题）。

Ordered Weighted L1（OWL）是一种在**回归估计过程**中同时完成"稀疏化 + 分组化"的正则化估计器，可作为现有去冗余机制的补充视角。

### 1.2 结论摘要

| 维度 | 结论 |
|------|------|
| 技术可行性 | ✅ 高 —— cvxpy 1.9.2 已安装，可实现 OWL 凸优化；无新增重依赖 |
| 数据就绪度 | ✅ 高 —— plans/40 B 层 `l3_signal_service` 已产出 2D 信号矩阵 + 因子收益矩阵，可直接作为 OWL 设计矩阵 |
| 与现有链路关系 | 🔶 补充而非替代 —— 信号聚类解决"信号冗余"，OWL 解决"定价因子冗余"，语义互补 |
| 统计合规 | ⚠️ 需按 AGENTS.md §4.1 可解释优先条款：两阶段检验 + 血缘登记 + 对照优于现有方案才可接入 |
| 推荐优先级 | **P2** —— 先做蒙特卡洛对照实验验证分组能力，再决定是否接入 L3 Step 1.8 旁路 |

## 二、OWL 方法摘要（技术要点）

### 2.1 正则项形式

$$\Omega_w(x) = \sum_{i=1}^{p} w_i |x|_{[i]}$$

- $|x|_{[i]}$：系数绝对值**降序**排列的第 i 个元素
- $w$：非递增权重向量（大的系数承受更大惩罚）
- 强 Schur 凸性 → 倾向把强相关变量的系数**拉得相等** → 分组机制来源

### 2.2 关键性质

1. **自动分组**：无需先验分组信息；载荷距离 $\|a_i - a_j\|_2 < \Delta_w/\|y\|_2$ 时两系数保证相等（平方误差损失下）
2. **稀疏 + 分组**：与传统 LASSO（只挑代表）不同，OWL 在惩罚中"抱团"
3. **两阶段流程**（Sun 2018/2019）：OWL 收缩 → 按系数聚类 → 组内正交检验（Cochrane 2011 思路）判定独立解释力
4. **实证**：90 候选因子模拟中 OWL 是唯一能聚出相关组并给相似系数的估计器；1980–2017 美股样本外对冲组合夏普最高，且能识别出市场因子

### 2.3 局限

- 正则化估计量难以直接做统计推断 → 必须配第二阶段检验
- 权重向量 $w$ 选择影响分组粒度（需调参）
- 计算开销高于闭式解（凸优化迭代求解）

## 四、OWL vs 现有机制对比矩阵

| 维度 | 信号相关性聚类（现值） | OWL（候选） |
|------|----------------------|------------|
| 输入 | 参考品种信号序列 2D 矩阵（L3）/全样本信号（L2） | 信号矩阵 X（n×p）+ 横截面收益 y |
| 分组依据 | 信号 Pearson 相关 → 层次聚类 | 载荷空间系数拉平（惩罚结构驱动） |
| 先验需求 | 阈值 + 链接方法 | 权重向量 w（无先验分组） |
| 稀疏化 | 簇内代表选择（top_n） | 惩罚本身置零 + 簇内系数相等 |
| 统计检验 | 无内置（靠 L3 Verifier/审计兜底） | 需两阶段组内正交检验（Sun 2018） |
| 定价语义 | 无（不区分"有解释力"与"冗余"） | 直接回答"哪组因子对横截面收益有独立解释力" |
| 计算成本 | O(n²) 相关矩阵 + 层次聚类（轻） | 凸优化迭代求解（重，但 p≤数百可接受） |
| 可解释性 | 直观（聚类图谱） | 系数分组（需 w 调参 + 检验佐证） |
| 数据依赖 | 仅信号序列 | 信号矩阵 + 收益矩阵（plans/40 已就绪） |

**关键洞察**：两者互补。聚类管"信号长得像不像"，OWL 管"对收益有没有独立贡献"。存在"信号不相关但共同驱动定价"与"信号相关但一个被噪声主导"两种聚类漏判场景，OWL 可补位。

## 六、接入方案评估（候选位置）

### 方案 A：L3 Step 1.8 旁路验证（推荐先做）

- **位置**：Step 1.8 信号聚类之后、Step 1.9 PCA 之前
- **方式**：`l3.owl.enabled` 开关（默认 false），启用时 OWL 输出"定价因子簇"，与信号聚类结果**交叉比对**：
  - 信号聚类剔除但 OWL 保留 → 说明信号相关但定价独立，人工复核是否放回
  - 两套都剔除 → 强冗余，可靠剔除
- **优点**：不动现有链路，先产出对照证据；开关化零风险
- **缺点**：多一套计算，需设定两套结果冲突时的裁决规则

### 方案 B：L2 准入补充检验

- **位置**：`_promote_to_elite` 相关预检后
- **方式**：候选因子加入精英池前，用 OWL 快速检验其对横截面收益的**增量解释力**，弱定价因子直接拒绝
- **优点**：从源头减少冗余入库；与正交化（GAP-I206）互补
- **缺点**：L2 候选评估已重，叠加凸优化需控开销；需样本外切割防数据窥探

### 方案 C：替换 Step 1.8

- **不推荐**。信号聚类输出直观、成本低、已覆盖信号冗余主场景；OWL 作唯一分组依据会引入 w 调参敏感性与两阶段检验依赖，违反"简单至上"。

## 七、风险与局限

1. **统计推断困难**：正则化估计量无直接置信区间，必须配两阶段检验，否则无法通过 AGENTS.md §4.1 可解释优先条款
2. **权重向量 w 敏感性**：w 决定分组粒度，需交叉验证或敏感性扫描，避免"调参式选组"被质疑数据窥探
3. **样本外纪律**：OWL 系数估计若用全样本，等同用未来收益定因子 → 必须时间切割（训练窗拟合 OWL → 检验窗验证）
4. **计算开销**：凸优化求解在 p=数百、n=数千时可接受（秒级），但高频迭代场景需 Safe Screening Rules 或缓存
5. **A 股尾部相关性**：尾部相关强的市场（A 股）OWL 分组缓解作用需样本外实测，不可照搬美股结论
6. **与现有结果冲突的裁决**：两套分组不一致时缺默认裁决规则，需在方案 A 中显式定义
