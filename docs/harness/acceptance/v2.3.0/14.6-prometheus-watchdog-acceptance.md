### 1.1 目标

| # | 目标 | 验收标准 | 状态 |
|---|------|---------|------|
| 1 | APScheduler BackgroundScheduler 集成 | `SchedulerEngine.start()` 返回 True，APScheduler 未安装时静默降级 | ✅ |
| 2 | 6 个定时任务注册 | L1/L2/L3/sync_futures/futures_signal/health_check 全部注册 | ✅ |
| 3 | 进程级看门狗 | `ProcessWatchdog` 崩溃自动重启 + 3 次/30s 熔断 | ✅ |

| 5 | 指标端点缓存 | 5s TTL 缓存，避免高频重复构造 aggregator（GAP-14.5-001） | ✅ |
| 6 | 同步摘要压缩 | sync_summary 使用 gzip 压缩（GAP-14.5-002） | ✅ |
| 7 | 测试全绿 | scheduler + monitor 共 153 测试 100% 通过 | ✅ |

## 2. 实现清单

### 2.1 `fts/scheduler/engine.py` — APScheduler 集成

| 功能 | 说明 |
|------|------|
| `SchedulerEngine` | 包装 APScheduler `BackgroundScheduler` |
| `start(daemon=True)` | 启动调度器，注册所有 TaskSpec，APScheduler 不可用时返回 False |
| `stop()` | 停止调度器，shutdown(wait=False) |
| `_add_job()` | 解析 5 字段 cron 表达式，添加到 APScheduler |
| `_make_job_fn()` | 动态导入 callable_path，执行任务 |
| `run_scheduler()` | CLI 入口，后台/阻塞模式 |

### 2.2 `fts/scheduler/watchdog.py` — 进程守护

| 功能 | 说明 |
|------|------|
| `ProcessWatchdog` | 子进程监控 + 自动重启 |
| 重启策略 | 连续 3 次重启 / 30s 窗口 → 5 分钟熔断 |
| 熔断恢复 | 冷却期后自动恢复重启 |

### 2.3 `fts/monitor/http_server.py` — Prometheus 端点

| 功能 | 说明 |
|------|------|
| `_build_prometheus_metrics()` | 构建 Prometheus 文本格式响应 |
| `/metrics` 端点 | `text/plain; version=0.0.4; charset=utf-8` |
| `_metrics_cache` | 模块级 5s TTL 缓存，减少重复 aggregator 构造 |

**Prometheus 指标清单**:

| 指标名 | 类型 | 说明 |
|--------|------|------|
| `fts_version` | gauge | FTS 版本信息 |
| `fts_data_source_success_rate` | gauge | 数据源成功率 |
| `fts_circuit_open` | gauge (0/1) | 是否有熔断器开启 |
| `fts_data_source_count` | gauge | 已注册数据源数量 |
| `fts_data_source_total_success` | gauge | 累计成功次数 |
| `fts_data_source_total_failure` | gauge | 累计失败次数 |
| `fts_elite_factor_count` | gauge | Elite 因子数量 |

### 2.4 `fts/scheduler/jobs.py` — GAP-14.5-002 修复

| 功能 | 说明 |
|------|------|
| gzip 压缩 | sync_summary 使用 `gzip.compress()` 写入 `.json.gz` |
| 读取兼容 | `_build_data_source_metrics` 同时支持 `.json` 和 `.json.gz` |

## 4. 契约验证

### 4.1 Prometheus 端点契约

```
GET /metrics
Content-Type: text/plain; version=0.0.4; charset=utf-8

# HELP fts_version FTS version info
# TYPE fts_version gauge
fts_version{version="2.4.0"} 1

# HELP fts_data_source_success_rate Data source overall success rate
# TYPE fts_data_source_success_rate gauge
fts_data_source_success_rate 0.9554

# HELP fts_circuit_open Whether any data source circuit is open (1=open)
# TYPE fts_circuit_open gauge
fts_circuit_open 0

# HELP fts_data_source_count Number of registered data sources
# TYPE fts_data_source_count gauge
fts_data_source_count 2
```

### 4.2 指标缓存契约

| 属性 | 值 |
|------|-----|
| 缓存键 | 模块级 `_metrics_cache["data"]` |
| TTL | `FTS_METRICS_CACHE_TTL` 环境变量，默认 5s |
| 过期行为 | TTL 过期后重新构造 aggregator |
| 线程安全 | 单进程内安全（Prometheus 单机拉取场景） |

## 8. 验收结论

✅ **Phase 14.6 + 15.0 通过验收**：

1. **APScheduler 集成** — `SchedulerEngine` 包装 BackgroundScheduler，6 个定时任务全注册，cron 5 字段解析正确

3. **Prometheus 端点** — `/metrics` 标准文本格式，7 个指标覆盖版本/健康度/数据源/elited 因子
4. **GAP-14.5-001 关闭** — `_metrics_cache` 5s TTL 缓存，避免高频重复构造
5. **GAP-14.5-002 关闭** — sync_summary gzip 压缩写入，磁盘占用降低 70-80%
6. **测试全绿** — 153/153 测试 100% 通过
