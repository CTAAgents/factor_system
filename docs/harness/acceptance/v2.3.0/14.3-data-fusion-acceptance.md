## 3. 实现要点

### 3.1 `FusionStrategy` 枚举

```python
class FusionStrategy(str, Enum):
    MEDIAN = "MEDIAN"            # 中位数（默认，抗异常值）
    MEAN = "MEAN"                # 算术平均
    WEIGHTED = "WEIGHTED"        # 按源权重加权平均
    HIERARCHICAL = "HIERARCHICAL"  # 优先级优先 + 异常值兜底
    TRIMMED_MEAN = "TRIMMED_MEAN"  # 去极值均值（N≥3 时最稳健）
```

### 3.2 `FusedOHLCV` 契约

```python
class FusedOHLCV(TypedDict):
    # 必填：与 FuturesOHLCV 8 必填字段对齐
    symbol: str; date: str; open: float; high: float; low: float
    close: float; volume: float; trace_id: str
    # 必填：融合元数据
    contributing_sources: list[str]  # 参与融合的源名列表
    fusion_strategy: str             # 融合策略名
    # 可选：期货专属
    amount: NotRequired[float]; hold: NotRequired[float]
    settle: NotRequired[float]; pre_settle: NotRequired[float]
    oi_change: NotRequired[float]; vwap: NotRequired[float]
    # 可选：融合元数据
    source: NotRequired[str]      # 主源名（字典序首个贡献源）
    disagreement_pct: NotRequired[float]  # 多源最大相对偏离
```

### 3.3 5 种策略行为

| 策略 | N=1 | N=2 | N=3 | N≥4 |
|:-----|:----|:----|:----|:-----|
| MEDIAN | 透传 | 均值（=中位数） | 第二个值 | 排序取中间 |
| MEAN | 透传 | 算术平均 | 算术平均 | 算术平均 |
| WEIGHTED | 透传 | 加权 | 加权 | 加权 |
| HIERARCHICAL | 透传 | 优先级优先/异常降级 | 优先级优先/异常降级 | 优先级优先/异常降级 |
| TRIMMED_MEAN | 透传 | 均值 | 去首尾均值 | 去首尾均值 |

### 3.4 默认源权重

```python
DEFAULT_SOURCE_WEIGHTS = {
    "TQ_LOCAL": 2.0,    # 通达信本地 — 最高权重
    "TQ_PYTHON": 2.0,
    "WIND": 1.5,        # 万得 — 字段最全
    "IFIND": 1.0,       # 同花顺
    "AKSHARE": 0.5,     # 兼容旧数据
    "DUCKDB_CACHE": 1.0,
    "SYNTHETIC": 0.0,   # 合成数据不参与加权
}
```

### 3.5 HIERARCHICAL 行为详解

```python
def _hierarchical(self, src_values, median):
    priority_src = min(src_values.keys())  # 字典序最小源 = 主源
    priority_value = src_values[priority_src]
    if median <= 0:
        return priority_value
    diff_pct = abs(priority_value - median) / median
    if diff_pct > self.outlier_threshold:  # 默认 0.5%
        return median  # 降级到中位数
    return priority_value
```

**注意**：当前实现以源名字典序作为"优先级"（最小为最高优先级）。生产环境中可由调用方在 `source_rows` 字典中按优先级顺序插入，或未来扩展为外部优先级表。
