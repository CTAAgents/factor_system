## 1. 任务目标

为 `FuturesDataAggregator` 增加多源交叉验证能力，检测同日期同合约多源 `close` 偏离中位数超过阈值，触发告警并记录。

1. **新增契约** `MultiSourceDisagreement`（`fts/core/contracts.py`）—— 告警数据结构
2. **`cross_check()` 方法** —— 同 symbol+date 多源 close 对比，偏离 > 阈值返回告警
3. **JSONL 告警日志** —— 追加模式写入 `data/data_source_disagreements.jsonl`
4. **主路径自动触发** —— `get_ohlcv()` 成功后自动对最近 N 天执行交叉验证
5. **失败隔离** —— 交叉验证失败不计入熔断计数器，不影响 K 线主路径
6. **可配置化** —— `enable_cross_check` / `cross_check_threshold` / `disagreement_log_path` 三个参数

端到端验证：5 场景（阈值内/外/单源失败/禁用/主路径触发）。

## 3. 实现要点

### 3.1 `MultiSourceDisagreement` 契约

```python
# fts/core/contracts.py
class MultiSourceDisagreement(TypedDict):
    """多源交叉验证告警（v2.3.0+ 14.2 新增）。

    当同一 symbol+date 的多源 close 偏离中位数超过 `cross_check_threshold`
    （默认 0.5%）时记录。每条告警对应一个 symbol+date 组合。
    """
    # 必填
    symbol: str                       # 品种代码（如 "RB0"）
    date: str                         # ISO 日期 "2026-08-04"
    prices: dict[str, float]          # {"TQ_LOCAL": 3540.5, "WIND": 3555.0, ...}
    median: float                     # 中位数（参考价）
    outliers: list[str]               # 偏离超阈值的源名列表
    # 可选
    max_diff_pct: NotRequired[float]  # 偏离中位数的最大百分比（小数，如 0.008 = 0.8%）
    threshold: NotRequired[float]     # 本次使用的告警阈值
    trace_id: NotRequired[str]        # 链路追踪 ID
    detected_at: NotRequired[str]     # ISO 时间戳
```

### 3.2 `cross_check()` 方法签名

```python
def cross_check(
    self,
    symbol: str,
    date: str,
    sources: Optional[list[BaseFuturesSource]] = None,
    trace_id: str = "",
) -> list[MultiSourceDisagreement]:
    """多源交叉验证：同日期同合约多源 close 对比，差异超阈值返回告警。

    Args:
        symbol: 品种代码（如 "RB0"）
        date: ISO 日期 "2026-08-04"
        sources: 参与交叉验证的源列表（默认 = 字段增强层）
        trace_id: 链路追踪 ID（HARNESS §5.5）

    Returns:
        MultiSourceDisagreement 列表。outliers 非空时同时追加一行到
        `disagreement_log_path`（JSONL 格式，追加模式）。
    """
```

### 3.3 核心算法（中位数偏离检测）

```python
def cross_check(self, symbol, date, sources=None, trace_id=""):
    if not self.enable_cross_check:
        return []

    # 默认源 = 字段增强层（K 线主路径只调一个源，不构成"多源"）
    if sources is not None:
        check_sources = list(sources)
    else:
        check_sources = list(self.enhancers) or list(self.sources)

    if len(check_sources) < 2:
        logger.debug("[cross_check] %s @ %s 源数量 < 2，跳过", symbol, date)
        return []

    # 1) 收集每个源的 close（异常被吞，不计入熔断）
    prices: dict[str, float] = {}
    for src in check_sources:
        try:
            if self._is_circuit_open(src.source_name):
                continue
            df = src.fetch_ohlcv_or_none(symbol, days=5, trace_id=trace_id)
            if df is None or df.empty or "close" not in df.columns:
                continue
            match = df[df["date"].astype(str) == date]
            if match.empty:
                continue
            price = float(match["close"].iloc[0])
            if price > 0:
                prices[src.source_name] = price
        except Exception as e:
            logger.warning("[cross_check] 源 %s 异常: %s", src.source_name, e)

    if len(prices) < 2:
        return []

    # 2) 计算中位数（参考价）
    median = float(np.median(list(prices.values())))

    # 3) 找出偏离 > 阈值的源
    outliers: list[str] = []
    max_diff = 0.0
    for src_name, price in prices.items():
        if median <= 0:
            continue
        diff_pct = abs(price - median) / median
        if diff_pct > max_diff:
            max_diff = diff_pct
        if diff_pct > self.cross_check_threshold:
            outliers.append(src_name)

    if not outliers:
        return []

    # 4) 构造告警记录（符合 MultiSourceDisagreement 契约）
    record = MultiSourceDisagreement(
        symbol=symbol, date=date, prices=prices, median=median, outliers=outliers,
        max_diff_pct=max_diff, threshold=self.cross_check_threshold,
        trace_id=trace_id, detected_at=datetime.now().isoformat(timespec="seconds"),
    )

    # 5) 写入 JSONL 日志（追加模式）
    self._write_disagreement_log(record)
    logger.warning("[cross_check] %s @ %s 多源分歧: %d 个 outlier, max_diff=%.4f",
                   symbol, date, len(outliers), max_diff)
    return [record]
```

### 3.4 默认源选择策略

| 场景 | 默认源 | 理由 |
|:-----|:-------|:-----|
| `enhancers=[WIND, IFIND]`（正常） | `enhancers` | 字段增强层独立于 K 线主路径，避免重复调用触发熔断 |
| `enhancers=[]`（无增强层） | `sources`（K 线源） | 兼容仅有 K 线主路径的场景 |
| 显式 `sources=[...]` | `sources` | 用户显式指定优先 |

### 3.5 主路径自动触发（`_maybe_cross_check`）

```python
def _maybe_cross_check(
    self,
    df: pd.DataFrame,
    symbol: str,
    trace_id: str,
) -> list[MultiSourceDisagreement]:
    """主路径尾部触发：对最近 N 个交易日自动交叉验证。

    触发条件：
    1. enable_cross_check=True
    2. enhancers 数量 ≥ 2（cross_check 需要多源对比）
    3. df 非空 + 含 date/close 列

    避免 K 线主路径源被重复调用而触发熔断计数器。
    """
    if not self.enable_cross_check or df is None or df.empty:
        return []
    if len(self.enhancers) < 2:
        return []
    if "date" not in df.columns or "close" not in df.columns:
        return []

    dates = sorted(df["date"].astype(str).unique().tolist(),
                   reverse=True)[:self.cross_check_recent_days]

    all_alerts: list[MultiSourceDisagreement] = []
    for date_str in dates:
        alerts = self.cross_check(symbol, date_str, trace_id=trace_id)
        all_alerts.extend(alerts)
    return all_alerts
```

**关键设计**：
- 触发条件严格（需 `enhancers ≥ 2`），避免无意义调用
- 默认检查最近 5 个交易日（可配 `cross_check_recent_days`）
- 返回值供 `FuturesDataLineage.disagreements` 字段填充

### 3.6 JSONL 告警写入

```python
def _write_disagreement_log(self, record: MultiSourceDisagreement) -> None:
    """追加一行 JSONL 到告警日志（不抛异常）。"""
    try:
        self.disagreement_log_path.parent.mkdir(parents=True, exist_ok=True)
        with self.disagreement_log_path.open("a", encoding="utf-8") as f:
            f.write(json.dumps(record, ensure_ascii=False) + "\n")
    except Exception as e:
        logger.warning("[disagreement_log] 写入失败: %s", e)
```

**示例输出**（`data/data_source_disagreements.jsonl`）：


### 3.7 与 14.1 熔断器的隔离设计

| 维度 | 14.1 熔断器 | 14.2 交叉验证 |
|:-----|:------------|:--------------|
| 触发条件 | 源连续 N 次 `fetch_ohlcv` 抛异常 | 多源 `close` 偏离中位数 > 阈值 |
| 计数器影响 | 计入熔断 | **不计入**熔断（避免互相干扰） |
| 恢复机制 | 冷却后探活 | 人工仲裁 / 调整阈值 |
| 写入位置 | 内存 `_breakers` 字典 | JSONL 追加日志 |
| 失败处理 | `_record_failure()` | `try/except` 吞掉，warn 日志 |
