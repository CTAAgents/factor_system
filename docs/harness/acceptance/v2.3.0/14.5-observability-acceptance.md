## 3. 调度任务 — `sync_futures_data`

### 3.1 任务规格

| 字段 | 值 |
|---|---|
| name | `sync_futures_data` |
| cron_expression | `30 17 * * 1-5`（工作日 17:30 收盘后） |
| callable_path | `fts.scheduler.jobs.sync_futures_data_job` |
| trace_id_prefix | `fts.sync` |
| 默认参数 | symbols=`FUTURES_SUBSET`（82 全品种，v2.89.0 起），days=500 |

### 3.2 工作流程

1. 生成 trace_id：`fts.sync.sched_YYYYMMDDHHMMSS`
2. 通过 `_build_default_aggregator()` 构造 `FuturesDataAggregator`（TQ_LOCAL/WIND/IFIND 探活）
3. 遍历 `symbols`（默认 25 个核心品种）调 `agg.get_ohlcv(symbol, days, trace_id)`
4. 统计：success / failure / total_rows / elapsed_seconds
5. 落盘 `data/_lineage/sync_summary_<ts>.json`（含完整 summary + 源状态 + 失败明细）

### 3.3 异常处理

- 单品种失败：捕获 + 计入 failures + 继续后续品种
- aggregator 构造失败：仅记日志，不抛
- 任何异常：外层 `except Exception` 兜底，job 不崩溃

## 4. 可观测性端点

### 4.1 `/metrics/data-sources` (GET)

**响应结构**:
```json
{
  "fts_version": "2.3.0-rc.1",
  "checked_at": "2026-08-04T18:00:00",
  "healthy": true,
  "summary": {
    "any_circuit_open": false,
    "total_success": 150,
    "total_failure": 7,
    "success_rate": 0.9554,
    "source_count": 2
  },
  "sources": {
    "TQ_LOCAL": {"consecutive_failures": 0, "circuit_open": false, ...},
    "WIND": {"consecutive_failures": 0, "circuit_open": false, ...}
  },
  "latest_sync": {
    "trace_id": "fts.sync.sched_20260804T173000",
    "success": 24,
    "failure": 1,
    "total_rows": 12000,
    "failures": [...]  // 截断到 10 个
  }
}
```

**判定规则**:
- `healthy = (not any_circuit_open) AND (success_rate >= 0.5)`
- `any_circuit_open = any(source.circuit_open)`

### 4.2 `/health` (GET) — 升级

**响应结构**:
```json
{
  "status": "ok",  // 或 "degraded"
  "timestamp": "2026-08-04T18:00:00",
  "data_sources": {
    "any_circuit_open": false,
    "source_count": 2,
    "sources": {
      "TQ_LOCAL": {"circuit_open": false, "consecutive_failures": 0, ...}
    }
  }
}
```

**状态判定**:
- `status = "ok"`：所有源正常
- `status = "degraded"`：任一源熔断（`circuit_open=true`）
- aggregator 初始化失败：保留 `status="ok"`，记 `data_sources_error`

### 4.3 `check_data_sources_status()` Python 接口

**返回字段**:
- `healthy: bool` — 全部源未熔断
- `source_count: int` — 探活成功的源数
- `any_circuit_open: bool`
- `sources: dict[str, dict]` — 各源详细状态
- `error: str` (仅异常时) — 错误信息

## 5. CLI 包装 — `scripts/sync_futures_data.py`

```bash
# 同步全品种（默认，FUTURES_SUBSET 82 个）
python scripts/sync_futures_data.py

# 指定品种
python scripts/sync_futures_data.py --symbol RB0 CU0 --symbol AU0

# 短回溯
python scripts/sync_futures_data.py --days 30

# 选择品种池
python scripts/sync_futures_data.py --universe stratified  # 60 品种

# JSON 输出（CI/监控集成）
python scripts/sync_futures_data.py --json

# 调试日志
python scripts/sync_futures_data.py --verbose
```

**退出码**:
- `0`：所有品种同步成功
- `1`：部分或全部失败
