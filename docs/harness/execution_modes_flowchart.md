## 模式选择

| 模式 | 适用场景 | 启动方式 |
|:-----|:---------|:---------|
| CLI 命令行 | 开发调试、手动执行、单次运行 | `fts evolution run --max-generations 3` |
| Scheduler 定时 | 生产环境自动运行 | `python -m fts.scheduler.engine` |
| Monitor 监控 | 持续监控、告警 | 内嵌于其他模式，自动启动 HTTP 端点 |

## 状态流转

```
[stopped] → [running] → [completed] → [circuit_broken] → [recovered/stopped]
     │                                              │
     └────────────────────── [paused] ──────────────┘
```

各循环状态持久化到 `memory/` 目录，通过 `fts monitor` 查看实时状态。

## 熔断策略

| 熔断类型 | 触发条件 | 恢复方式 |
|:---------|:---------|:---------|
| Token 熔断 | 消耗 > budget * 2.0 | 等待下一个调度周期 |
| 低 IC 熔断 | 连续 5 代 IC < 0.005 | 手动重启或等待次日 |
| 失败率熔断 | 失败率 > 95% | 检查配置后重启 |
| 连续低质量 | 连续 3 代质量分 < 30 | 手动重启 |

## 质量评分卡

因子晋升 elite 前需通过质量评分卡评估（50 分制）：

| 维度 | 分值 | 说明 |
|:-----|:-----|:-----|
| IC 稳定性 | 0-8 | IC 一致性 + IC 波动率 |
| Sharpe | 0-8 | 年化夏普比率 |
| 换手率 | 0-8 | 月度换手率 |
| 容量 | 0-5 | 资金容量评估 |
| 频率 | 0-5 | 数据频率 |
| 覆盖率 | 0-5 | 品种覆盖率 |
| 鲁棒性 | 0-6 | 跨品种/跨期稳定性 |
| 经济逻辑 | 0-5 | 四维经济逻辑评分 |

**分级标准**:
- A 级: ≥ 40 分 → 精英池（附加质量分）
- B 级: ≥ 30 分 → 精英池
- C 级: < 30 分 → 质检淘汰
